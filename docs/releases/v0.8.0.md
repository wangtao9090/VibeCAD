# VibeCAD v0.8.0

VibeCAD v0.8.0 promotes Guided Photo V3 into the bounded mechanical image-to-CAD product path while
preserving the existing 38-tool MCP, Task Kernel, review, Revision, and Release authorities.

## Highlights

- Ordinary photos can produce one editable extruded or revolved mechanical part after capture
  quality, coplanar scale, occlusion, and geometry-completeness screening and independent confirmation
  of blocking dimensions.
- The host-local workflow returns exactly `PHOTO_READY`, `NEEDS_CAPTURE`, or `OUT_OF_ENVELOPE` before
  CAD Task creation. New evidence invalidates the provisional plan and forces a fresh evidence matrix.
- Axis-aligned slot geometry now compiles to native Sketcher lines, arcs, and deterministic editable
  constraints instead of a flattened approximation.
- Public outcome evidence covers an annular washer, a rounded-square fan spacer, and a calibration
  block with one blind pocket. Missing thickness and multi-object clutter stop before Task creation.
- Real Codex, Claude, and WorkBuddy paths each produced a distinct review draft through the same
  MCP/managed-FreeCAD authority, with fully constrained sketches, valid one-solid BReps, parameter
  edit probes, and FCStd/STEP delivery.
- Authenticated daemon clients now reconnect and replay one exact request once after an idle
  disconnect. The bounded internal program envelope is 128 parameters and 8,192 IR nodes.

## Boundaries

This release does not claim photo-only metrology, arbitrary or occluded reverse engineering,
automatic hidden-geometry recovery, CAD semantic merge, Fillet/Chamfer, freeform surfaces,
sculpture, or general STEP/STL import. A user must still review and explicitly accept a draft before
it advances project HEAD.

## Upgrade

Install the `vibecad==0.8.0` wheel or the `VibeCAD.mcpb` release asset, and activate the separate
`vibecad-agent-skill-0.8.0.zip` in the host's supported Skill directory. Existing project, Revision,
Task, and Release data remain compatible; the server package epoch stays at 4.
