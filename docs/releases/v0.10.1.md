# VibeCAD v0.10.1

VibeCAD v0.10.1 is a cross-platform hotfix for the managed FreeCAD runtime and its
installation guidance.

## Fixed

- Windows now verifies and launches the managed FreeCAD environment with the same explicit
  DLL, executable, and Python-module activation used by Workers, the supervisor, and the GUI
  launcher. A successfully installed FreeCAD environment is no longer misreported as
  `runtime_unavailable` because a bare Python process cannot find `FreeCAD.pyd` or its DLLs.
- Runtime verification retains the Windows DLL-directory handles for the full import lifetime
  and reports structured diagnostics for import, timeout, and child-process failures.
- An inconclusive Windows verification receives one bounded retry. If installation completed but
  verification timed out, VibeCAD preserves the complete environment and can repair only the
  readiness receipt on the next attempt instead of downloading FreeCAD again.
- The WorkBuddy setup documentation now calls out the connector trust step and distinguishes the
  supported Windows PowerShell and macOS Terminal installation procedures.
- The English and Simplified Chinese installation examples now select and install `v0.10.1`.

## Compatibility

- Supported product platforms: Windows x86-64 and macOS x86-64/arm64.
- The default product path remains the VibeCAD-managed FreeCAD runtime.
- Existing projects and durable data are preserved during upgrade.

Install the `vibecad==0.10.1` wheel or the `VibeCAD.mcpb` release asset. The standalone
WorkBuddy skill is published as `vibecad-agent-skill-0.10.1.zip`.
