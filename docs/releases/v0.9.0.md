# VibeCAD v0.9.0

VibeCAD v0.9.0 adds bounded parametric linkage and semantic edge treatments to the existing
mechanical image-to-CAD path while preserving the 38-tool MCP, Task Kernel, review, Revision,
Release, durable schema, and runtime-epoch authorities.

## Highlights

- A private derived design parameter may use a structured, same-unit affine expression with one to
  eight source terms and a finite constant. Cycles, unit mismatch, inconsistent initial values, and
  out-of-range live values fail before CAD mutation.
- Derived relationships are installed as native FreeCAD expression bindings on the existing
  parameter carrier. Source-parameter edits propagate through transitive consumers and remain
  authenticated after save, close, and reopen.
- Generated Pad, Pocket, Hole, and Revolve features may be followed by bounded Fillet or Chamfer
  treatments selected through stable source-feature, source-sketch-geometry, and section/sweep-role
  semantics rather than transient `EdgeN` names.
- Fillet supports one constant radius, independent per-edge radii, or a linear start-to-end radius
  law on one oriented nonclosed edge. Chamfer supports independent symmetric per-edge sizes.
- Ambiguous or missing topology, duplicate targets, direction reversal, invalid geometry, kernel
  failure, or verifier failure rolls back the whole candidate transaction.
- The canonical Agent Skill documents the same strict IR shapes, selection rules, clarification
  boundary, and safe-failure behavior for Codex, Claude, WorkBuddy, and compatible MCP hosts.

## Boundaries

This release does not infer Fillet or Chamfer dimensions from photographs alone. It does not add
arbitrary imported STEP edge treatment, tangent-chain propagation, variable Chamfer, multi-point
radius laws, complex surface blends, semantic merge, manual-topology repair, freeform surfaces,
sculpture, or general STEP/STL import. The user must still review and explicitly accept a draft
before it advances project HEAD.

## Upgrade

Install the `vibecad==0.9.0` wheel or the `VibeCAD.mcpb` release asset, and activate the separate
`vibecad-agent-skill-0.9.0.zip` in the host's supported Skill directory. Existing Project, Task,
Revision, Release, and visual-reconstruction data remain compatible; the server package epoch stays
at 4 and the public tool count stays at 38.
