# VibeCAD v0.10.0

VibeCAD v0.10.0 adds an evidence-gated path from sealed ordinary photographs to an ordinary
review-required CAD Task. It preserves runtime epoch 4, the 38-tool public MCP surface, the public
`adopt_reconstruction` schema, and the existing Project, Task, Revision, Release, and runtime pins.

## Highlights

- Image bytes are sealed into an exact ImageSet and independently rechecked for capture quality.
- Raw provider observations are rebound to their exact image batch, planar calibration, fitted
  geometry, and proposal-derived CAD consumers. A caller cannot choose a smaller
  `required_features` set or supply a precomputed admission result.
- Admission is persisted as a private digest-bound sidecar, limited to 192 KiB, and replayed exactly
  after restart. Initial adoption and adoption recovery both revalidate it before any review Task or
  project effect.
- Missing, stale, ambiguous, orphaned, or tampered evidence fails closed. A complete admission still
  creates only a `REQUIRE_REVIEW` Task; it never accepts a draft or advances project HEAD.
- The first admitted geometry envelope is one Body with an origin-XY rectangular profile and Pad,
  optionally followed by 1–16 circular locations in one reversed `THROUGH_ALL` Hole. Pad length and
  Hole semantics require explicit user confirmation.

## Boundaries

This is not universal photo reverse engineering and does not recover hidden geometry. Photo
admission does not support slots, arcs, Pockets, Revolves, datum or expression-driven construction,
patterns, mirrors, surface modifiers, edge treatments, freeform surfaces, sculpture, or semantic CAD
merge. Those capabilities may exist in other explicit design paths without being admitted from this
photo-evidence contract.

Candidate-specific real-host package acceptance has not completed. The current Claude CLI attempt
reported `loggedIn=false`; no Codex, Claude, or WorkBuddy result should be inferred for this candidate
until each host runs its own exact-package smoke.

## Upgrade

Install the `vibecad==0.10.0` wheel or the `VibeCAD.mcpb` release asset, and activate the separate
`vibecad-agent-skill-0.10.0.zip` in the host's supported Skill directory. Existing durable data remain
compatible; runtime epoch 4, the 38-tool public MCP surface, and the runtime dependency pins are
unchanged.
